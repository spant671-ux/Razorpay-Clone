# Razorpay Clone

This project is a visual clone of the Razorpay landing page built to practice and learn **Tailwind CSS**. 

**Note:** The backend for this project is not implemented. This is strictly a frontend development learning exercise focused on layout, styling, and utilizing Tailwind CSS to recreate a professional, modern web interface.

## Technologies Used
- HTML5
- Tailwind CSS v4
- PostCSS
